# PointProgrammerNet：可加、定长、无全局 Max 的点云状态网络

PointProgrammerNet 把无序点流写入少量固定尺寸的 Fast Weight Program（FWP）矩阵。点与点之间的全部信息交换都经过这些状态；写入后，网络不再访问历史点特征，也不对解码点做全局 Max。它用少量静态精度换取固定历史内存、顺序无关的增量更新和连续坐标查询。

## 定型版本

- 分割：`fwp_dual_read_partition_multiscale_seg`
- 分类：`pointprogrammer_state_multiscale_residual_main_r25`

两个任务共享同一写入哲学：三个等容量、结构相同但参数独立的二阶 FWP，每个状态均为 `128×170`。三个 FWP 使用相同的连续单位质量 partition 键，半径从 `0.08/0.20/0.60` 初始化并独立学习。尺度只是初始化先验，并未给某个 FWP 指定语义；其内容变换和最终用途由训练决定。

分割与分类只在状态读出方式上不同。分割有明确的查询坐标，因此并列读取三个状态；分类没有查询点，因此从整个固定状态生成摘要，以中尺度摘要为参考并用另外两个摘要作有界残差修正。

## 设计哲学

### 状态是唯一的跨点接口

写入完成以后，一个点不能直接读取或比较其他点。历史信息只能通过固定 FWP 状态传递。这一约束使离线点集、分块点流和连续帧共享同一表示。

### 连续性优先于离散选择

模型不使用 FPS、KNN、硬体素、Top-k 或全局 Max。空间键和查询都随坐标连续变化，因此输入中没有出现过的坐标也可以被查询。模型不会宣称该性质自动带来更高静态精度；它是流式更新和连续场预测的结构基础。

### 容量公平，尺度分离

三个 FWP 的矩阵尺寸、键形式和读出宽度相同，避免把容量差异误认为专家分工。实验表明完全相同的初始半径会使三个状态覆盖范围重叠，因此保留三个相隔的半径初始化。网络仍可学习最终半径和各分支内容。

### 非线性放在状态两端

点值在写入前由独立 MLP 编码；FWP 本身保持可加；读取的统计量再由逐点或逐状态 MLP 解释。这样既保留非线性表达能力，又不破坏中间状态的代数性质。

## 可加二阶状态

对于尺度 `s` 和点 `x_i`：

```text
g_si = MLP_s(x_i)
v_si = [1, x_i, g_si, x_i⊗g_si, second(x_i), g_si⊙g_si]
M_s  = Σ_i k_s(x_i) v_si^T
```

其中 `k_s(x_i)` 是对128行归一化的连续正键：

```text
k_sj(x) ≥ 0,       Σ_j k_sj(x) = 1
```

值宽为170，对应质量、坐标、内容均值、坐标与内容交叉矩、空间二阶矩和特征二阶矩。三个 `float32` 状态共 `3×128×170×4 = 261,120` 字节，约255 KiB；该内存与历史点数和帧数无关。

对任意不相交点集 `A`、`B`：

```text
M_s(A ∪ B) = M_s(A) + M_s(B)
```

因此普通累加与点顺序、输入分块和并行归并方式无关，只存在浮点求和误差。

## 分割读出

```text
点流 ──写入──> {M_fine, M_middle, M_broad}
查询点 q ──连续键──> 分别读取三个 FWP
当前点 clean 特征 ─┐
三个状态读出 ──────┼─> 拼接 ─> 共享逐点 MLP ─> 部件标签
物体类别 one-hot ──┘
```

三个状态读出保持分离并直接拼接，不再把旁路预先压进某个“主干”。当前点自身的 clean 特征负责保留点身份，FWP 读出负责跨点上下文。预测 `q` 只依赖当前查询、类别和三个固定状态，不依赖其他查询点，也没有第二次全图扫描。

新增点时，先把该点的外积贡献加到三个状态，再查询它即可。若旧点的预测需要响应新证据，可以按需重新查询该点坐标，无需重建或保存所有旧点特征。

最终分割候选具有366,389个参数。三种子5轮筛选结果为 point accuracy `90.28±0.23%`、instance mIoU `76.92±0.12%`、category mIoU `72.93%`。其完整20轮结果尚未生成，不能用旧模型的完整结果代替。

当前已有的完整无 Max 参考是较早的 `fwp_dual_read_r5_mix02_seg`：seed 0 为 point accuracy `92.86%`、instance mIoU `82.21%`、category mIoU `78.62%`。它证明无 Max 路线可行，但不再是论文定型结构。

## 分类读出

```text
点流 ──写入──> 三个128×170 FWP ──删除点张量
每个状态：逐行统计解码 ─> 行 MLP ─> 两个连续 softmax 摘要
middle_summary + λ·tanh(W[fine_summary, broad_summary])
                         └─> LayerNorm ─> MLP ─> 类别
```

分类不保存点坐标或点特征，不执行逐点读取，也不使用 Transformer 或全局 Max。softmax 只在固定的128个状态行上操作，其读出成本不随历史点数增加。

中尺度摘要是分类读出的参考项，细、粗摘要提供有界修正。最终训练把残差比例学到 `0.117`、混合量学到 `0.079`，说明主摘要承担主要判断而两条旁路提供小幅有效校正。三个状态仍然等容量；“主干”只存在于分类读出的代数形式中。

最终分类模型仅把中尺度半径参数置于 `25×` 学习率组，其他半径和全部网络参数使用普通学习率。20轮 seed 0 结果为 clean accuracy `86.71%`、density accuracy `82.58%`，参数量529,426。相对旧状态残差分类器分别提高 `1.30` 和 `1.46` 个百分点。

## 流式状态操作

一批新点的状态贡献为：

```text
B_t = K_t^T V_t
```

支持以下固定内存操作：

```text
追加：      M_t = M_(t-1) + B_t
合并：      M(A ∪ B) = M(A) + M(B)
删除：      M_new = M_old - M(deleted_points)
指数衰减：  M_t = ρ M_(t-1) + B_t
```

后续可引入 Delta 更新：

```text
M_t = ρM_(t-1) + βK_t^T(V_t - K_tM_(t-1))
```

普通求和严格不引入时间方向。衰减和 Delta 在帧级引入状态转移，但仍与帧内点顺序无关，状态尺寸保持不变。跨帧使用时，各帧必须位于一致坐标系并采用一致归一化。

分类新增证据只需更新三个矩阵并重新运行固定状态读出。FWP 的变化对新增点贡献线性可加，最终类别分数经过非线性 MLP，因此 logits 本身不宣称严格线性。

## 为什么去掉全局 Max

全局 Max 对静态点集很有效，但要求在全部解码点之间进行离散比较。随着点流增长，必须保留点特征，或者从历史点重新解码后再比较。PointProgrammerNet 禁止这条旁路，获得：

- 与历史长度无关的固定状态；
- 新点和新帧的矩阵化增量写入；
- 状态的合并、删除、衰减与分布式归并；
- 分割在任意坐标上的连续查询；
- 分类写入后不保留任何历史点。

代价是静态精度略低。已完成实验中，无 Max 分割比对应 Max 模型低约1个 instance-mIoU点；最终无 Max 分类比参数配平 PointNet低 `0.89` 个 clean accuracy点。论文的核心主张是固定状态流式推理及其精度权衡，而非静态榜单最优。

## 定型依据

三种子快速消融给出以下关键证据：

- 分割中，在统一 partition 键下使用多尺度半径，比三个相同半径提高约 `0.51` instance-mIoU点。
- 多尺度条件下统一为 partition 键，比混合键提高约 `0.10` instance-mIoU点和 `0.82` category-mIoU点。
- 分类中，固定状态残差读出相对三路直接拼接提高 `2.67` clean点和 `3.77` density点。
- 分类中，中尺度半径 `25×` 学习率相对 `1×` 将 density提高 `0.92` 点，同时保持 clean基本不变。

已经排除的附加组件包括软极值、三阶矩、上下文写入门控、竞争路由、FiLM、额外状态跳连、Transformer式状态混合和任何解码点全局 Max。这些组件没有稳定收益，不属于最终架构。

## 主张边界

当前已验证静态分割、静态分类、状态可加性和固定尺寸。长期动态序列中的位姿误差、状态漂移、真实在线延迟以及 Delta 更新的任务精度仍需单独实验。论文可以严格主张无解码点全局 Max、固定历史状态和可加更新，不能把尚未完成的动态实验写成已验证结论。
