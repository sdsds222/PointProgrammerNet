## 相对 PRL 版的改动（四处，实验内容与数字未改）

**一、补充材料并入正文。** TVC 无页数限制，且本次不提交 supplementary，因此
`../manuscript/supplement.tex` 的全部内容按主题并入对应章节：

- 分割精确读出与数值下限 → 3.2 节
- 分类精确归一化与行描述子 → 3.2 节
- 两条命题及其证明、连续性论证 → 3.3 节
- 五个受控筛选表 → 4.5 节
- 复现说明 → 文末「数据可用性」

**二、新增 4.2 节「并行状态与单一状态」。** 这是原版没有的论点，用已有实验数据补上：

| 配置 | 状态数 | 参数量 | 实例 mIoU | 类别 mIoU |
|---|---|---|---|---|
| 仅主状态（因果对照） | 1 | 484,914 | 74.68 | 70.50 |
| 主状态加宽至 256 行 | 3 | 485,298 | 74.79 | 70.53 |
| 并行状态，保守半径学习率 | 3 | 484,914 | 75.73 | 71.03 |
| 并行状态，更强残差混合 | 3 | 484,914 | 75.88 | 70.97 |
| 已发布三状态模型 | 3 | 341,909 | 77.22 | 73.08 |

数据来源：`artifacts_seg/dual_read_capacity_probe/segmentation_results.json` 与
`artifacts_seg/strict_equal_seg_readout_probe/segmentation_results.json`，
两者协议一致（5 epoch、种子 0/1/2、train-limit 2048、test-limit 512）。

对照组 `fwp_dual_read_main_only_r5_mix02_seg` 在代码里的定义是
「保留完整模型与初始化，但令局部与粗尺度状态无法影响输出」，
所以两侧参数量与初始权重完全相同，是严格配对的因果消融。

**三、5.2 节写明压缩瓶颈。** 原版只说「固定状态是一个信息瓶颈」，
现在明确写成：点一旦写入，状态就是后续唯一可见的东西，
**因此起约束作用的是状态而不是读出**，并用筛选数据支撑
（改解码器动 0.30±0.30，改状态配置动一个百分点以上）。

**四、相关工作一节从一段扩写为五个小节，并加一张对比表。** 原版只有 6 句、7 条引用；
现在按「在吸收一个点时放弃了什么」把相关工作分组，逐族说明技术差异：

- **对称池化与度量邻域**（PointNet / PointNet++ / Deep Sets）：max 不可逆；度量邻域随点集变动而需重建；
  Deep Sets 可加但求和进单一全局向量，无空间地址，无法按坐标读取。
- **基于学习中心的固定摘要**（VLAD / NetVLAD / PointNetVLAD）：累加器形状与本文相同，
  但残差是一阶、分配在特征空间，**且块内归一化与 $L_2$ 归一化把可加性消掉了**——
  这是与本文最锋利的一条差异。
- **对固定隐变量的注意力**（Set Transformer / Perceiver IO）：坦承「用查询读固定隐变量出稠密结果」
  是 Perceiver IO 的贡献；差别在编码端 softmax 使输入耦合、隐变量不可合并，
  以及查询是位置嵌入而非数据同空间的坐标。
- **有界循环状态**（线性注意力 / FWP / PointMamba）：PointMamba 用空间填充曲线序列化，
  状态依赖遍历顺序，两个部分状态不能相加。
- **本架构拒绝做的事**：写入时刻的单条拒绝——任何把一个点的写入与另一个点耦合的东西
  都不得进入持久状态；密度归一化、中心化与非线性解释全部推迟到读出。
  附一张四性质对比表（顺序无关写入 / 可加状态 / 有界状态 / 坐标读取），带三条脚注说明例外。

新增 5 条参考文献（VLAD 2010、NetVLAD 2016、PointNetVLAD 2018、Perceiver IO 2022、PointMamba 2024），
作者、标题、会议、年份均已逐条核对；**页码请在校样阶段复核**。参考文献总数 7 → 14。

其余全部段落、公式、表格、图与数字均与 PRL 版一致，逐项核对过。
